# KINGMAKER
### Play the World. Build the Future. Own Your Creation.

KINGMAKER is a browser-based nation-building and world-strategy prototype. Build your economy, develop infrastructure, research technology, manage diplomacy, and expand your borders by claiming neutral territories.

## Current build: World Engine 0.4

### Playable systems
- **Nation management** — name your nation and choose a government style.
- **Economy** — manage food, materials, credits, population, stability, power, and influence.
- **Infrastructure** — build farms, workshops, markets, academies, and power grids.
- **Trade** — buy and sell resources at changing simulated prices.
- **Diplomacy** — improve relations with rival NPC nations.
- **Research** — unlock technologies that improve production and governance.
- **Territorial expansion** — claim six neutral regions, each with a permanent production bonus.
- **World Director** — receive local strategic advice based on your current nation state.
- **Creator Studio** — register creations in your local game profile.
- **World history** — review a log of important game events.
- **Save system** — autosave in the browser, plus JSON export and import.

## Run the game

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Your game saves automatically in that browser's local storage.

No build tools, server, API key, or installation are required for the current prototype.

## Save data

- Autosaves are stored in the browser on the device where you play.
- Use **Export Save** to back up your nation to a JSON file.
- Use **Import Save** to restore a previously exported game.
- Clearing browser site data can remove local saves, so export backups regularly.

## Important prototype notes

- NPC behavior, diplomacy, prices, and production are simulated locally.
- The World Director is a local rule-based game assistant, not a connected AI service.
- Creator registrations are game records, not legal copyright registrations.
- The game does not process real payments, cryptocurrency, or real-world assets.
- Multiplayer, online accounts, and cloud saves are not implemented yet.
