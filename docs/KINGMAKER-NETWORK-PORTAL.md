# KINGMAKER Network portal — Genesis preview

## Current delivered web experience
- Responsive desktop/mobile landing portal with KINGMAKER visual identity.
- Product vision and staged game/network roadmap aligned to README.
- Optional EIP-1193 injected-wallet address display. No signing, transactions, approvals, key access or custody.
- Installable PWA metadata and service-worker cache; browser install instructions for iOS, Android and desktop.
- Local-only demo activity streak and points counter.
- Clearly marked future sponsor-video inventory placeholder.

## Not live and must not be advertised as live
- Cryptocurrency mining or background compute mining.
- A real token, token balance, reward, exchange listing, airdrop, or payout.
- Accounts, server-side activity ledger, cloud sync or anti-Sybil controls.
- WalletConnect / mobile deep-link session support (the current connection uses an injected EIP-1193 provider).
- Advertisements, video ad delivery, sponsor contracts or ad revenue.
- Native signed Android APK, Windows EXE or macOS installer. This is an installable Progressive Web App (PWA), not a native binary.

## Revenue and advertising
The portal reserves space for future clearly labelled sponsor placements. No ad SDK or autoplay has been added. Monetization requires a real ad/sponsor provider account, approval, privacy/cookie consent as applicable, brand-safety review, and measurement. Do not promise users a reward for viewing ads until a provider explicitly permits incentivized inventory and the reward ledger exists. Ad income depends on eligible impressions, geography, format, fill rate, viewability and advertiser demand; it is not guaranteed.

## Production mining/network requirements
A mobile browser cannot honestly be described as mining a cryptocurrency just because a timer or button runs. Before any real mining/reward system: define the consensus or contribution mechanism, token utility and emission policy, anti-Sybil controls, server-side ledger, rate limits, abuse monitoring, legal classification, energy/security impact, and independent contract/security review. Avoid hidden CPU mining and never run mining without explicit, informed consent.

## Roadmap alignment
The public roadmap mirrors the project README: game quality; next-generation 3D world; AI systems; civilization technology depth; Web3 architecture and token utility design; security-tested wallet/on-chain implementation; staged web release and operations.
